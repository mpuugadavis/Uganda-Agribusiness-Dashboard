# 🇺🇬 Uganda Agribusiness Sector Analysis

## 📌 Project Overview
![Overview Dashboard](<Screenshot 2026-09-13 094519.png>)
This project analyzes Uganda's agribusiness sector using *synthetic, modeled and calibrated data*
informed by sources such as FAOSTAT, UBOS and MAIIF.

The analysis explores agricultural production, commodity performance, regional patterns, trade, value addition and other factors influencing Uganda's agribusiness sector.

## 🎯 Objectives

* Analyze agricultural production and commodity performance.
* Identify high-performing commodities and regions.
* Examine export values and trade patterns.
* Assess value addition and market-related indicators.
* Generate data-driven insights relevant to Uganda's agribusiness sector.

## 📊 Key Questions

* Which commodities contribute most to agricultural production?
* Which regions perform best across key agribusiness indicators?
* Which commodities have the highest export value?
* What are the major production and trade patterns?
* Which areas show potential for greater value addition?

## 🔍 Key Insights
* Sugarcane outperformed all other agricultural commodities in production by volume generating a substancially higher ouput compared to the rest of the commodities
* The Central Region had the best overall performance in production but production varied considerably and alternately per year
* Export performance varied considerably across commodities.
* Value addition showed opportunities for further agribusiness development.

## ⚠️ Data Disclaimer

The dataset used in this project is synthetic, modeled and calibrated data developed for analytical and portfolio purposes. It is informed by publicly available agricultural statistics and does not represent official Uganda government statistics.

The analysis should therefore not be interpreted as an official statistical publication.
